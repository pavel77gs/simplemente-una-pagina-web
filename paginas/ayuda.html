Cuidado con main y master:

  1. La rama principal en Github es main, si al crear tu fork y hacer init sale que estás en la rama master, cambiale el nombre a main con git branch -m main

Sección creada el 26/11/26

Trabajando en otras ramas:

  1. Si lo prefieres, haz los cambios en otra rama mediante git switch -c TU_NUEVA_RAMA para crear una nueva rama y cambiar a ella en un solo paso.
  2. Una vez terminados los cambios, vuelve a la rama main: git switch main y usa el git merge TU_NUEVA_RAMA. Habrás fusionado los cambios de TU_NUEVA_RAMA con la rama main.

¿Cómo puedo aportar?

  1. Crea una carpeta donde quieras guardar los archivos de esta página.
  2. Copia el enlace del repositorio: https://github.com/pavel77gs/simplemente-una-pagina-web.git
  3. Con git clone copia este repositorio.
  4. Haz los cambios que quieras, no te olvides de documentar cada uno mediante commits.
  5. Una vez hechos tus cambios, súbelo con git push origin main (para la rama principal)
  6. Si te da error, es porque no eres colaborador/a. Tendrás que pasarme tu nombre de usuario para añadirte y darte permisos de escritura.
  7. Te llegará la invitación para colaborar a tu correo, abrelo y acepta
  8. Disfruta de la página :)
  9. Para seguir añadiendo cambios, asegúrate de actualizar el repositorio en tu disco local: git pull

O si prefieres hacer los cambios en un fork en vez de volverte un colaborador directo del repositorio principal...

  1. Crea un fork del repositorio en github (ponle el nombre que quieras).
  2. Crea un directorio donde quieras guardar los archivos del fork.
  3. Clona el fork de la misma forma que se clona el repositorio original.
  4. Actualiza los archivos del directorio de GitHub en tu disco local con git pull en caso de que hayan cambios.
  5. Haz los cambios que quieras, siempre dejando commits de cada uno. Recuerda: git commit -m "Escribe el cambio que has hecho aquí"
  6. Sube el fork a github con git push origin main(o a cualquier otra rama que hayas elegido)
  7. En github, hazme un pull request. Vete a tu fork, a la pestaña "Pull requests" y al botón "New pull request"
  8. Me llegará tu pull request, te lo aceptaré cuando pueda.

Recomendaciones

  • Comprueba el estado del repositorio: git status
  • Comprueba las diferencias que no se han guardado: git diff
  • Asegurate de estar en la rama main con git branch. Si no, usa git switch main
  • Mira la lista de cambios con git log, o con menos detalles: git log --oneline
  • La primera vez que vayas a hacer un push, usa el parámetro -u para facilitar los siguientes pulls y pushes: git push -u origin main
  • Cualquier otra recomendación que tengas añádela aquí :)
